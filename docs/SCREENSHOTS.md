# Screenshots

The README shows no images beyond the banner yet. The dropdown has to be opened on a real Omarchy desktop to capture it, so these are still to take. Save each as a PNG in `docs/` and reference it from the README.

| File | What to capture |
|---|---|
| `docs/panel.png` | The dropdown open, showing all three lanes and the Available list |
| `docs/bar.png` | The bar with the Omaseiton icon highlighted |
| `docs/themes.png` | The same dropdown under two or three different Omarchy themes, side by side |
| `preview.png` (repo root) | A tidy crop of `panel.png`. The marketplace picks this up as the listing image |

Capture with `omarchy capture screenshot`, or `grim -g "<x>,<y> <w>x<h>" file.png`.
